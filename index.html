Configuration-Driven Pipeline ELITEBUILD.EXE

  • Place your source files in src\ and JSON target specs in Build_Configurations\*.config.
  • Drop or symlink EliteBuild.exe into the project root (using EliteSymlinker.exe) and run it with zero per-repo boilerplate scripts.
  • Automatically kills locking executables, compiles GccTargets / MSVC targets, logs all pipe output to EliteBuild.log, and invokes EliteEasySigner.exe.
  • Supports --ai-mode across tools to suppress interactive prompts for headless CI and AI agent execution.

Example Build_Configurations/Tool.config JSON SPEC

{
    "GccTargets": [
        "g++ -m64 -O3 -o \"BuildOutputx64\\MyTool.exe\" \"src\\main.cpp\" -lole32 -luuid -lshell32"
    ],
    "KillProcesses": [
        "MyTool.exe"
    ]
}
